# ✨ About the Project

**Grammar Dost** makes English grammar easier to understand through simple explanations, Urdu translations, visual examples, and interactive practice.

Designed with Grade 8 learners in mind, the app pairs every lesson with familiar examples and bilingual support, helping students build confidence one concept at a time.
